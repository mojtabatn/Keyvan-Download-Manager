### What's new in 0.2.3

- **The browser's "Download video" button can be closed, and stays out of the way.** It has a **×** to hide it for that video. If it would sit on top of a site's own buttons (a "close" or "details" button in a video pop-up, for example), it moves to another corner of the video by itself. In the extension's popup you can turn it off for a single website. **Reload the KDM extension** to get this.
- **The extension no longer disappears from Edge and Chrome after a restart.** The portable version runs from a temporary folder that is deleted when KDM closes, so a browser that loaded the extension from there lost it. KDM now keeps a permanent copy in its data folder (**Settings → Browser integration → Open extension folder**). Remove the old KDM extension from `edge://extensions` or `chrome://extensions`, then **Load unpacked** and pick that folder, once.
- **The "Update Available!" button works.** It did nothing after GitHub renamed the repository's letter case in 0.2.0 and 0.2.1. If you use an older version, install this one by hand once.
- Includes everything from 0.2.1 and 0.2.2: the right video from the browser button on pages with several videos, the "Download complete" window, and the fix for "GitHub responded 403".
